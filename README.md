# Semantic Search Chatbot

An intelligent Semantic Search & Q&A Chatbot built with Python, Hugging Face **Sentence-Transformers**, and **Vector Embeddings**. This project demonstrates how to perform semantic text matching and information retrieval using state-of-the-art embedding models (`all-mpnet-base-v2` / `all-MiniLM-L6-v2`).

---

## 🌟 Key Features

- **Semantic Understanding**: Finds conceptually similar answers rather than relying strictly on exact keyword matching.
- **Hugging Face Integration**: Powered by `sentence-transformers` for generating high-dimensional dense vector embeddings.
- **Fast Similarity Computation**: Computes Cosine Similarity across document vectors to retrieve top relevant responses in milliseconds.
- **Interactive Interface**: Designed to run seamlessly in Jupyter Notebooks or Google Colab environments.
